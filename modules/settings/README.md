# Module 3: Settings (`modules/settings`)

## Responsibility
Responsible for user-facing settings, preferences, account management, and client performance tuning.

## Submodules
1. `account/`: User profile details, subscription plan management (Woobi Premium).
2. `appearance/`: Color themes, typography sizing, high-contrast mode.
3. `privacy/`: Analytics consent, camera permissions, data cleanup.
4. `notifications/`: Daily outfit reminder schedule, streak countdown notifications.
5. `performance/`: Three.js graphics quality presets (Ultra, High, Battery Saver), shadow resolution toggles.

## Public Interface Contract
The module exposes its public API through `index.js`.
