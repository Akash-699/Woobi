# Module 2: 3D Studio Features (`modules/3d-studio-features`)

## Responsibility
Responsible for interactive functionality, virtual try-on, garment interactions, and styling algorithms built on top of the 3D Studio components.

## Submodules
1. `virtual-try-on/`: Clothing overlay, try-on modal triggers, instant garment swap.
2. `garment-interactions/`: Click-to-inspect 3D garments, raycast hover effects, rail navigation.
3. `outfit-recommendations/`: 3-look daily outfit board generator, occasion filtering, color matching.
4. `avatar-customization/`: Gender selection (Male/Female), styling review hints.
5. `animations/`: Interactive door opening kinematics, stage rotation animations.
6. `saved-looks/`: Daily outfit upload streak, countdown timer, wear history, lookbook.

## Public Interface Contract
The module exposes its public API through `index.js`.
